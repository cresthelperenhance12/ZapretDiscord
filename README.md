> ### АНТИВИРУСЫ
> Антивирус может отреагировать на WinDivert.  
> Для работы zapret нужен WinDivert — инструмент перехвата и фильтрации сетевого трафика.
> Его применяют и легитимные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Цитата из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы классифицируют файлы WinDivert как инструменты повышенного риска или хакерские утилиты. В результате файл удаляется и помещается в карантин. В названии такого обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы умеете корректно настраивать исключения, предпочтительнее добавить исключение. Если вы не уверены в своих действиях, рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Включите безопасный DNS (Secure DNS)
    * В Chrome откройте настройку «Использовать безопасный DNS» и укажите поставщика DNS, отличный от «Поставщик по умолчанию»
    * В Firefox выберите «DNS через HTTPS», режим «Персональный», затем «Выбрать провайдера/поставщика» и вручную укажите URL. Например: `https://dns.google/dns-query` (поставщик Cloudflare может быть заблокирован)
    * В Windows 11 Secure DNS можно настроить непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот вариант рекомендуется пользователям Windows 11
    * На роутере Keenetic включите параметр «Транзит запросов». Если он выключен, настройка и работа Secure DNS на компьютере могут нарушиться

2. Загрузите ZIP- или RAR-архив с [последнего релиза](https://github.com/cresthelperenhance12/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте «Разблокировать». Пользователям 7-Zip и PeaZip этот шаг можно пропустить

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите подходящий файл
    * Чтобы найти работающий вариант: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для автоматического запуска: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) — запуск стратегии вручную

  Ручной запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **проверяйте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные инструменты:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — убрать стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб (автозапущенной стратегии и WinDivert)
  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  Чтобы изменение вступило в силу, перезапустите стратегию.  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — управлять фильтрацией сервисов, перечисленных в `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который доступен без zapret, но не открывается с ним.  
  Скобки показывают режим:
    - `none` — проверка IP не применяется
    - `loaded` — IP сверяется со списком
    - `any` — фильтр действует на любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить используемый фейк другим файлом из `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины сбоев zapret.  
  В конце проверки можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это может помочь, если приложение внезапно перестало работать
  - **`Run Tests`** — проверить стратегии с помощью встроенной утилиты:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️ Частые вопросы и неполадки

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным BAT-файлом, а не через service, должен открыться `winws.exe` (обход). Найти его можно на панели задач.  
Если процесса нет, обратитесь к [#522](https://github.com/cresthelperenhance12/zapret-discord-youtube/issues/522)

### Не удалось подобрать стратегию
- Откройте командную строку с правами администратора
- Выполните в ней команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не открывается веб-версия Telegram
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если ваш файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого Блокнота
  - В появившейся папке откройте `hosts` в текстовом редакторе, запущенном от имени администратора
  - Вставьте скопированное в конец файла `hosts` (либо замените ранее добавленные аналогичные строки)
  - Сохраните файл и проверьте подключение. Если проблема осталась, убедитесь, что изменения действительно сохранились.

#### Результат не гарантирован. Если этот способ не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/cresthelperenhance12/tg-ws-proxy) или любым публичным.

### Обход не работает или перестал помогать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение стратегии может привести к тому, что работавший раньше вариант перестанет обходить блокировку.
> Здесь доступно несколько стратегий. Если ни одна не подходит, создайте новую, взяв существующую за основу и изменив её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и устраните найденные ошибки

- Проверьте, что адрес нужного ресурса указан в списке доменов или IP

- Поочерёдно испытайте другие варианты (**`ALT`**, **`FAKE`** и прочие)

- При необходимости выполните полную переустановку (см. инструкцию ниже)

- Дополнительная информация: [#765](https://github.com/cresthelperenhance12/zapret-discord-youtube/issues/765)

### Как выполнить полное обновление или переустановку?
- Сохраните файлы и данные, которые добавляли самостоятельно
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Затем запустите `service.bat` -> `Run Diagnostics`; исправьте обнаруженные ошибки и в конце выберите Y
- Удалите папку zapret
- Загрузите свежую версию `zapret-discord-youtube-...` со [страницы релизов](https://github.com/cresthelperenhance12/zapret-discord-youtube/releases)
- Щёлкните по архиву правой кнопкой, откройте свойства и, если внизу справа есть «Разблокировать», включите её, нажмите «Применить» и «ОК»
- Распакуйте архив в новую папку в корне диска; избегайте пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте доступ к ресурсам. Если они недоступны, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- Найдя работающий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service` -> выберите стратегию

### Не запускается игра или приложение при включённом zapret

- В `service.bat` проверьте, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` — в **`none`**. Другие значения могут повлиять на ресурсы, которые вы не собирались фильтровать.

### Античит сообщает о WinDivert

- Следуйте инструкции: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Подмените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё отображается среди служб

1. В командной строке Windows (Win+R, `cmd`) узнайте имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив имя из предыдущей команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8F-использование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если работавшая стратегия больше не помогает, проверьте остальные варианты.
- См. обсуждение [#251](https://github.com/cresthelperenhance12/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8F-использование)
- Сначала выясните, какая стратегия открывает YouTube, и запустите её
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord
- Проверьте, заработало ли приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если там он работает, можно пользоваться веб-версией.
- Если браузерная версия тоже недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. обсуждение [#252](https://github.com/cresthelperenhance12/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/cresthelperenhance12/tg-ws-proxy)
- Также можно подключиться через бесплатные MTProto-прокси из интернета

### Не работают игры

Игры различаются, поэтому проверить и исправить каждую из них невозможно.

Для начала попробуйте универсальный вариант:
- Обновите ipset через `service.bat` и включите `Game Filter`
- Если это не помогло, дополнительно включите `ipset any`

Учтите: режим `ipset any` может мешать открытию многих сайтов. Не оставляйте его постоянно включённым. Лучше выясните IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте тему в разделе [Discussions](https://github.com/cresthelperenhance12/zapret-discord-youtube/discussions), а не в issues, и дождитесь ответа других игроков.

## 🗒️ Как добавить адреса других ресурсов

Списки для обхода можно настроить вручную:
- **`list-general-user.txt`** — домены; поддомены также учитываются
- **`list-exclude-user.txt`** — домены, исключённые из обработки (например, когда IP сети присутствует в `ipset-all.txt`, но конкретный домен фильтровать не нужно)
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, исключённые из обработки
  - Файлы с суффиксом **`*-user.txt`** появятся автоматически при первом запуске `zapret` или `service.bat`
